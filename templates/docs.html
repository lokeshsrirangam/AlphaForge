Quick start

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
python app.py

Open http://127.0.0.1:5000, pick a ticker (for example ^NSEI, RELIANCE.NS, SPY or BTC-USD) and press Run Backtest.

Timeline convention

This is the rule that keeps the backtest honest:

day t    : see close[t], compute signal and decide the target position
day t+1  : order executes at close[t+1]        (Execution = next close)
day t+2  : the position earns close[t+2] / close[t+1] - 1

"Same close" execution trades at the close used to compute the signal. It is optimistic and is offered only for comparison.

Metrics

  • CAGR: compound annual growth rate of the net equity curve.
  • Volatility: standard deviation of daily returns times the square root of the trading days per year.
  • Sharpe: mean excess daily return divided by its standard deviation, annualised. Shown with its standard error (iid approximation), so you can see how much of it could be luck.
  • Sortino: like Sharpe, but divides by downside deviation only.
  • Max drawdown: largest peak-to-trough fall of the equity curve.
  • Calmar: CAGR divided by the absolute max drawdown.
  • Time in market: share of days with an open position.
  • Cost drag: total trading costs paid, as a percent of capital (additive approximation).
  • Trades: one trade is one continuous run of holding the asset. Its return is the compounded net return over the run.

Research diagnostics

  • Return calendar: compounds the strategy's net daily returns within each calendar month. The first and last displayed months can be partial.
  • Market regime attribution: classifies each return using the previous session's close relative to its 200-session SMA, then reports conditional daily return, volatility, Sharpe and positive-session rate against buy and hold. The indicator warm-up is excluded; regime samples are non-contiguous, so no regime CAGR is reported.
  • Walk-forward validation: selects parameters on training windows and evaluates them on later, non-overlapping test windows. Treat the result as one out-of-sample diagnostic, not a guarantee of future performance.

HTTP API

POST /api/backtest with a JSON body using the field names above.

curl -X POST http://127.0.0.1:5000/api/backtest \
  -H "Content-Type: application/json" \
  -d '{"ticker": "^NSEI", "start_date": "2012-01-01", "cost_bps": 10, "target_vol": 15}'

The response contains meta, metrics, comparison (strategy vs buy & hold), regimes, warnings, trades and charts (Plotly JSON, including the monthly return heatmap). Invalid input returns HTTP 400 and a data problem returns HTTP 502, both with an error message.
